# Backbone shared FP8 expert qualification

`v41_backbone_shared.rs` loads the official shared expert for each of the 40 backbone layers and owns independent captured execution waves. The FP8 projections and clamped SwiGLU implementation in `v41_shared_ffn.rs` are shared with dSpark; its adapter still checks the owning expert stage. The sequence is K32 FP8 5120→2304 gate/up projections, FP32 clamped SwiGLU rounded to BF16, then K32 FP8 2304→5120 down projection. Gate clamps at +10 and up clamps at ±10, as in the pinned reference.

Each layer retains 36,529,920 device bytes for native tensors and packed scales. Each wave owns its scratch, aligned FP32 alpha, input, three intermediate buffers and result. Wave budgets are 74,244 bytes at capacity 1, 702,468 at 16, 3,387,396 at 80, 10,801,156 at 256, 43,204,612 at 1024 and 172,818,436 at 4096. Weight and wave admission reject a budget one byte short before allocation. Weights remain borrowed through wave lifetime, and queued work drains before output publication or storage release.

`execute_ffn` consumes the block's normalized `FfnInput`, checks its layer, execution identity, row count, extent and device, copies into stable owned input, and recaptures when the live row count changes. The completed shared contribution retains the block execution identity. Raw component execution returns unbound output. Failed calls and graph clearing unpublish output. This contribution must still be combined with the actual routed experts; it is not a complete FFN result.

Both RTX PRO 6000 GPUs passed 55 owner cases each: all 40 layers at 80 rows, plus capacities 1, 16, 256, 1024 and 4096 for layers 0, 20 and 39. Each case exercised two independent waves borrowing one weight owner, two changed inputs, graph replay, byte-exact agreement between waves, missing/wrong-row graph rejection and budget guards. The daemon and external fixtures built successfully.

The reusable `scripts/qualify-ds41-backbone-shared.py` checks 110 numerical sets per GPU against the hash-locked official kernels and `Expert.forward` activation. Gate/up and down projections retain rtol 0.008 and atol 0.002; activation from identical native gate/up inputs is exact. Maximum gate/up error was 0.0078125 and down error from the same intermediate was 0.00390625. The fully chained comparison had maximum absolute error 0.00390625 and maximum RMS error 0.00007415816799039021. Quantization-discontinuity propagation is bounded explicitly from the differing BF16 intermediates; this is not a full-model equality claim. The reference quantizer uses the already documented TileLang 0.1.8 `tir.disable_vectorize` override to avoid its shared-memory aliasing race, with no arithmetic changes.

A separate composed fixture passed on both GPUs for layers 0, 2, 7, 8, 14, 20, 24 and 39, with 16 requests and five rows each. It produces real attention, applies the block mHC boundary, and feeds the resulting normalized FFN input into the shared expert. It checks matching execution identity, rejects a different layer, and verifies repeated output bytes. Its final block finish still uses the explicitly labeled identity-FFN fixture: routed MoE is not yet connected. The shared contribution is independently numerically checked on those actual handoff inputs.

After extracting the common code, the existing three-stage dSpark fixture retained exact outputs in all 18 cases per GPU, with unchanged committed rings. These fixtures use their established synthetic checkpoint and do not prove real full-model dSpark execution.

`ds41-backbone-shared-qualification.json` records source, native library, fixture, payload and weight hashes plus numerical results and terminal logs. Four-Spark routing/transport integration, full-model execution, vision, scheduler integration and performance qualification remain open.
