# Native V4.1 mHC boundaries

`ds41rt_v41_hc_pre` collapses four BF16 residual streams using the incoming FP32 pre-mix, with FP32 products/sums and one final BF16 round-to-nearest conversion. `ds41rt_v41_hc_post` expands a BF16 sublayer result with FP32 post coefficients and adds the mixed residual, also rounding only the final result. Combination coefficients use `[source,destination]`, matching the official reference's sum over the source axis. Products and sums explicitly avoid fused multiply-add to preserve reference intermediate FP32 rounding. Kernels use wide offsets, reject invalid geometry and output/input overlaps, and allocate no workspace.

The library-borrowing Rust handle validates buffer sizes. dSpark terminal execution now owns residual `[5,R,4,5120]` and incoming pre-mix `[5,R,4]` buffers and enqueues collapse before final normalization, shared-head projection, Markov sampling and confidence. Its inputs are residual, pre-mix and anchor IDs; upstream stage execution must supply the shifted pre-mix, rather than recomputing coefficients from the final hidden state. The collapsed state remains the confidence input, while vocabulary projection uses its normalized version.

Synthetic signed/asymmetric pre/post/combination coefficients passed bitwise comparison to the pinned reference operations on both RTX GPUs at 1, 16 and 80 rows, including changed-input graph replay and output-alias rejection. The existing vocabulary/Markov/confidence and five-step sampling graph checks also passed against the updated native library. These checks do not qualify coefficient generation/Sinkhorn, complete layer execution, the Rust terminal owner or full serving.

The additional residual/pre-mix buffers require 3,278,080 bytes at 16 requests. Terminal storage is now 104,368,448 bytes, and two capacity-80 expert/terminal waves plus resident dSpark tensors require 8,293,027,672 bytes before the shared head and other excluded coordinator/cache allocations. The native library and Rust daemon builds passed; exact hashes and numerical evidence are in `ds41-hc-qualification.json`.
